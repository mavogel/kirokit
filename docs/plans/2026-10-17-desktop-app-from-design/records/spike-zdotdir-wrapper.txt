# Spike: zsh startup wrapper keeps the bundled CLI first and the app's settings exported (2026-10-17)
Wrapper folder (ZDOTDIR) holds .zshenv .zprofile .zshrc .zlogin; each sources the person's own "$HOME/<file>" with ZDOTDIR="$HOME".
The wrapper .zshrc then runs:
  path=("$KIROKIT_BIN" ${path:#$KIROKIT_BIN})
  export KIROKIT_REPO="$KIROKIT_APP_REPO" KIRO_HOME="$KIROKIT_APP_KIRO_HOME"
